# PORTFOLIO
A retro Game-inspired interactive web portfolio featuring pixel art, animations, and a nostalgic interface. Explore projects and visuals through a playful, vintage computer experience.

This project is a Retro Video Game-style Interactive Portfolio, designed to recreate the look and feel of vintage computer systems while showcasing my work, projects, and creative skills. The goal is to provide visitors with a unique, immersive experience that combines nostalgia with modern web technologies.

The portfolio features a top-panel navigation system, mimicking classic operating system menus, allowing users to access different sections, open “windows,” and interact with content in a playful and engaging way. Blank spaces in the interface are brought to life with pixel art, animations, and dynamic visuals, giving each interaction a retro gaming vibe.

The pixel art is custom-generated, allowing images to be transformed into retro-style graphics, enhancing the overall vintage aesthetic. Animations and interactive elements make the portfolio feel alive, inviting users to explore, click, and engage rather than just scroll.

Built entirely with HTML, CSS, and JavaScript, this portfolio is lightweight, responsive, and easy to customize. All design elements are modular, enabling simple updates to style, layout, and content. While there’s no backend required for basic functionality, optional integrations like Google Apps Script can add dynamic content, such as live project data or portfolio statistics.

This portfolio is more than a showcase—it’s an experience. It combines creativity, interactivity, and nostalgia to create a memorable impression, demonstrating both design skills and web development capabilities. Whether you’re exploring pixel art, animations, or the retro OS interface, every element is crafted to highlight projects in a fun, engaging, and visually distinct way.
